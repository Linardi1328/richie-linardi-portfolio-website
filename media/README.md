# Media staging

Use this folder to manually add **public-safe media assets** that you may want to implement later on the portfolio website.

The live site already keeps runtime assets under `public/` (for example `public/basketball`, `public/branding`, `public/portraits`, and `public/projects`). Keep `media/` as the manual staging/inbox area; when an asset is approved, move or copy it into the correct `public/` subfolder and reference it from the site code.

## Good candidates

- Portfolio project screenshots and demo images
- Approved basketball photos/videos
- Logos and branding assets
- Certificates or achievement visuals that are intentionally public
- Social/profile graphics intended for the portfolio

## Public-repository rule

Do not commit private documents, secrets, personal IDs, private contact details, or media you do not have permission to publish.

## File conventions

- Prefer descriptive lowercase kebab-case filenames.
- Keep originals where practical and avoid duplicate exports.
- Group related files into clear subfolders if the staging area grows.
