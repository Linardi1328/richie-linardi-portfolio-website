## Automatic freshness

Project detail pages fetch public GitHub repository activity with hourly revalidation. The source repository's latest push is displayed separately from the curated implementation review date. Failed, rate-limited, malformed or private responses do not produce a fresh-activity claim. No GitHub credential is sent or required.

This refreshes repository activity. Biography, achievements, event captions and implementation claims remain source-reviewed editorial content; a new commit cannot automatically verify them.
